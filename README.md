# Roour Chen · AI 产品经理个人网站

[访问个人网站](https://roourchen.github.io/RoourChen-website/)

深色星空、山景与女性人物插画构成首页背景，搭配紫粉渐变标题、半透明卡片与响应式布局。使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。

## 页面内容

- 个人介绍与关注方向。
- 链接到公开仓库的精选项目：拆拆 ChaiChai、AI 产品开箱工具包、GitHub Radar、知识库评测工作流。
- 指向项目 README 的实践指南入口。
- “文章与思考”分栏，展示公众号「小皮蛋oxo」的两篇文章；卡片可在新标签页打开微信公众号原文。
- GitHub 个人主页与 WeChat 联系入口；微信按钮可复制公开微信号。

项目文案基于对应公开仓库的简介与 README。页面不填入未经提供的工作年限、学历、真实姓名、联系方式、项目业务成果或 Star 数量。项目以公开实践展示，不据此声明其全部原创归属。

## 本地预览

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:8000`。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构、介绍、项目与链接 |
| `styles.css` | 深色主题、布局、动画和手机适配 |
| `script.js` | 导航、手机菜单、页脚年份 |
| `assets/hero.png` | 经用户选定风格生成的网站背景插画 |
| `assets/favicon.svg` | 网站图标 |

背景是 AI 生成的风格插画，不是网站主人真实照片。字体使用系统字体；页面不依赖外部字体、分析脚本或付费接口。不收集或发送访客输入。

## 发布与更新

GitHub Pages 从 `main` 分支根目录发布。修改对应文件并推送到 `main` 后，等待仓库的 **pages build and deployment** 完成。

导航、项目卡片和实践指南都是可点击链接。手机菜单支持展开、点选关闭和 Esc 关闭。页面支持键盘焦点和系统的减少动态效果设置。

后续完善个人资料时，编辑 `index.html`，以真实信息替换介绍与联系入口即可。
